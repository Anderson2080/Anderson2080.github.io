一、算力账本：伪命题与物理极限

Test-Time Compute 的隐含假设是：推理阶段增加 FLOPs 可线性提升模型输出质量。该假设在 8K 上下文内近似成立，超过 32K 后失效。原因不在算法，在 HBM 带宽墙。

计算账本：Llama 3 70B 在 FP8 精度下，权重占用 70GB。单张 H100 SXM 的 80GB HBM3e 仅剩 10GB 给 KV Cache。KV Cache 大小公式：2 × layers × heads × head_dim × seq_len × batch × bytes_per_param。以 80 层、64 heads、128 head_dim 计，单 token KV Cache = 2 × 80 × 64 × 128 × 1 × 1 = 1.31MB。100K 上下文单请求 = 131GB。80GB HBM3e 连一个完整 100K 上下文都装不下，必须分片到多卡。NVLink 4.0 双向 900GB/s，分片后每 token 生成需跨卡同步 KV Cache，延迟从 0.8μs 升至 12μs。NVLink 成为最大拥塞节点。

功耗账本：HBM3e 每 GB/s 带宽功耗约 3.5pJ/bit。NVLink 4.0 每 bit 传输功耗 1.8pJ/bit。硅光互联理论值 0.5pJ/bit，但激光器电光转换效率 15%，实际系统功耗 3.3pJ/bit。硅光互联在 100Gbaud 下，每通道功耗 4.2pJ/bit，高于 NVLink 铜缆。硅光优势仅在 500 米以上距离成立，机架内铜缆仍是物理最优解。

成本推演：8 卡 H100 节点，100K 上下文并发 4 请求，KV Cache 占用 524GB，需 7 个节点。跨节点互联延迟 45μs，每 token 生成时间从 22ms 升至 67ms。吞吐量下降 67%。每百万 token 推理成本从 $0.42 升至 $1.27。Test-Time Compute 的边际收益在 32K 上下文后转为负值。

二、架构解剖：为什么现有方案是纸上谈兵

HBM3e 堆叠 12 层 DRAM die，TSV 穿孔密度 10,000/mm²。热密度 0.8W/mm²，结温上限 95°C。风冷散热极限 0.3W/mm²。液冷可至 1.2W/mm²，但 TSV 热应力导致良率跌至 62%。HBM4 计划 16 层，热密度 1.1W/mm²，液冷下良率 48%。每 GB HBM3e 成本 $12，HBM4 预计 $18。80GB HBM3e 成本 $960，占 H100 物料成本 23%。

KV Cache 碎片化：PagedAttention 将 KV Cache 分页 16MB，碎片率 12%。vLLM 实测有效带宽利用率 41%。原因：HBM3e 行激活延迟 45ns，页表遍历增加 3 次行激活。每 token 生成额外 135ns。100K 上下文下，KV Cache 访问延迟占总生成时间 18%。

SRAM 面积局限：H100 的 50MB L2 缓存占 die 面积 28%。若将 KV Cache 全部放入 SRAM，100K 上下文需 131GB SRAM。台积电 N5 工艺 SRAM 密度 0.021μm²/bit。131GB = 1.05×10¹² bit，面积 22,050mm²。H100 die 面积 814mm²。需 27 个 die 拼接。CoWoS 封装极限 3 个 die。物理不可行。

硅光互联：Intel 硅光模块 100Gbaud 下，激光器功耗 80mW，调制器 12mW，探测器 8mW。总功耗 100mW。传输 100Gbps，每 bit 功耗 1pJ。但激光器热漂移 0.1nm/°C，需 TEC 控温，额外 150mW。实际每 bit 功耗 2.5pJ。NVLink 铜缆 1.8pJ/bit。硅光在 2 米内无优势。

三、商业账本：推理成本曲线的指数发散

Test-Time Compute 的边际收益：8K 上下文，每增加 1K 上下文，准确率提升 2.1%。32K 上下文，每增加 1K 上下文，准确率提升 0.4%。100K 上下文，每增加 1K 上下文，准确率提升 0.07%。边际收益递减。

推理成本：8K 上下文，每百万 token $0.18。32K 上下文，$0.42。100K 上下文，$1.27。成本曲线指数发散。原因：KV Cache 线性增长，HBM 带宽固定，跨卡同步延迟非线性增长。

商业结论：Test-Time Compute 在 32K 上下文后无商业可行性。HBM 带宽墙是物理极限，硅光互联无法在 2 米内突破铜缆功耗。KV Cache 碎片化导致 59% 带宽浪费。现有架构下，推理成本曲线无法收敛。华尔街对 Test-Time Compute 的定价需重估。
