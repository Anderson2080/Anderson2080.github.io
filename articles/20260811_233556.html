一、算力账本：伪命题与物理极限

Test-Time Compute的叙事是：模型在推理时“思考”更久，能解决更复杂的问题。但物理账本不撒谎。以FP8精度为例，HBM3e的峰值带宽为8.0 TB/s（SK海力士规格），而B200的FP8稠密算力为9 PFLOPS。算力与带宽的匹配公式：所需带宽 = 算力 / 算术强度。对于Transformer解码，算术强度约为每参数2次FLOP（含注意力），因此9 PFLOPS需要4.5 TB/s的带宽才能喂饱。HBM3e的8.0 TB/s看似够用，但实际有效带宽仅为理论值的70%（因刷新开销与TSV串扰），即5.6 TB/s。算力利用率 = 5.6 / 9 = 62%。这已是乐观值。若引入长上下文（128K tokens），KV Cache的读写将占用额外带宽，利用率跌至45%以下。

功耗账本更冷酷。B200的TDP为1000W，其中HBM3e接口功耗占25%（250W），TSV穿孔的热密度达1.2 kW/cm²，超过核反应堆燃料棒的0.5 kW/cm²。散热成本在数据中心层面为每千瓦时0.12美元（工业电价），单卡年电费 = 1000W * 24h * 365 * 0.12 = 1051美元。若部署10万卡集群，年电费1.05亿美元，仅维持45%的算力利用率。华尔街的模型若假设90%利用率，误差达2倍，估值锚点即崩塌。

二、架构解剖：为什么现有方案是纸上谈兵

KV Cache碎片化被当作软件缺陷，实则是SRAM面积与HBM带宽的物理矛盾。以Llama-3 70B为例，每token的KV Cache大小为1.2 MB（40层 * 8头 * 128维 * 2字节）。100K上下文需120 GB，超过单卡HBM3e的80GB。多并发请求（如1024路）需122 TB存储，只能外溢到NVLink（1.8 TB/s）或PCIe Gen5（128 GB/s）。推演：1024路并发，每路生成1K tokens，总KV写入 = 1024 * 1K * 1.2MB = 1.2 TB。若全部走NVLink，传输时间 = 1.2TB / 1.8TB/s = 0.67秒。但NVLink同时承载梯度同步与张量并行流量，实际可用带宽仅30%，即0.54 TB/s，延迟增至2.2秒。对比纯HBM访问（5.6 TB/s有效），延迟差3.2倍。用户感知的“卡顿”不是算法问题，是互联拓扑的物理瓶颈。

SRAM面积是另一堵墙。B200的SRAM容量为192MB（片上），但KV Cache的索引表（页表）在100K上下文下需2.4 MB/请求，1024路并发需2.5 GB，远超SRAM。页表只能放HBM，每次访问增加200ns延迟。注意力计算（FlashAttention）虽能分块，但块大小受SRAM限制（192KB/块），导致HBM访问次数增加4倍。数学上，最优块大小 = sqrt(SRAM容量 / 数据宽度) = sqrt(192KB / 2B) = 310 tokens。超过此值，HBM带宽成为硬约束，算力利用率线性下降。

三、硅光互联：成本曲线与距离的残酷博弈

硅光被吹捧为“算力解药”，但物理参数揭示其适用边界。硅光收发器的能量效率为0.5 pJ/bit（含激光源与调制器），铜缆（DAC）为2.5 pJ/bit。然而，硅光的固定成本高企：每根光纤的耦合损耗0.5 dB，需额外激光器功率，且封装良率仅85%（vs 铜缆99%）。总成本模型：硅光模块单价$800（含DSP），铜缆$200。在机架内（距离<2米），铜缆的延迟（0.1 ns/m）与功耗（2.5 pJ/bit）仍具优势，因为硅光的激光器闲置功耗（50 mW/通道）在短距下无法摊销。距离超过2米，硅光的低pJ/bit优势才显现：10米链路，硅光总功耗 = 0.5 pJ/bit * 10^9 bit/s * 10 = 5W，铜缆 = 25W。但数据中心机架间平均距离为5-10米，硅光仅节省20W/链路，而成本增加600美元/链路。投资回收期 = 600 / (20W * 0.12美元/kWh * 8760h) = 28.5年。华尔街若按5年折旧计算，硅光在机架内是负NPV项目。

更深的陷阱是带宽密度。硅光的单模光纤带宽为100 Gbps/波长，但波分复用（WDM）需额外激光器阵列，热漂移导致波长偏移0.1 nm/°C，需温控（功耗+15%）。对比HBM的TSV带宽密度（每mm² 1.2 TB/s），硅光的每mm²带宽仅0.4 TB/s（含调制器面积）。硅光在芯片间互联的物理优势，被封装面积和热管理成本抵消。结论：硅光适用于跨数据中心（>100米），而非机架内。市场叙事混淆了这两个场景。

四、推演终局：算力利用率的数学天花板

综合以上，构建一个真实系统的算力利用率公式：利用率 = min(1, 带宽有效值 / (算力 / 算术强度)) * (1 - 碎片化损耗) * (1 - 互联损耗)。代入B200：带宽有效值5.6 TB/s，算力9 PFLOPS，算术强度2 FLOP/byte，碎片化损耗30%（KV Cache外溢），互联损耗20%（NVLink拥塞）。利用率 = min(1, 5.6/4.5) * 0.7 * 0.8 = 0.62 * 0.56 = 34.7%。这意味着每1000美元硬件投入，只有347美元转化为有效计算。提升路径只有三条：增加HBM带宽（物理极限，TSV密度已到1.2 kW/cm²热墙）、减少KV Cache（算法压缩，但精度损失）、或缩短互联距离（架构重构，成本指数上升）。

对冲基金的定价模型应基于此：若AI推理需求年增3倍，而算力利用率仅34.7%，则需3倍硬件采购才能满足需求。但HBM3e的产能（SK海力士2025年出货量约1.2亿GB）与CoWoS封装产能（台积电月产6万片）构成硬约束。供需缺口 = 需求算力 / (利用率 * 单卡算力) - 可用卡数。按2025年需求200 EFLOPS（推理），需卡数 = 200E / (0.347 * 9E-3) = 6.4亿张，远超全球产能（约500万张）。缺口128倍，价格弹性将推高HBM单价至$30/GB（当前$15/GB），单卡成本从$30K涨至$45K。这就是物理账本的终局：不是软件优化能解决的，是材料与热力学的死刑判决。
