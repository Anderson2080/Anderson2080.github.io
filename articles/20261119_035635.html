一、算力账本：Test-Time Compute 的边际收益坍塌与功耗刚性

市场将 OpenAI o1 类模型的“思考时间”等同于可无限堆叠的算力红利。建立账本：单次前向推理在 FP8 精度下，70B 稠密模型每 token 需 2×70G FLOPs ≈ 140 GFLOPs。若 Test-Time Compute 将采样次数从 1 提升至 64，单请求算力膨胀至 8.96 TFLOPs。在 H100 SXM 的 989 TFLOPS FP8 峰值下，理论耗时 9.06 毫秒——但真实约束在内存侧：每 token 需读取全部 70GB 权重，HBM3 的 3.35TB/s 带宽使单 token 解码延迟锁定在 20.9 微秒，64 次采样即 1.34 毫秒纯权重搬运，算力利用率被压在 12% 以下。

功耗账本更残酷。H100 在 FP8 推理负载下实测能效约 0.38 J/token（含 HBM 与 NVLink 活动功耗）。64 次采样使单请求能耗达 24.3 J。当并发请求从 1K 升至 100K，单日能耗从 2.1 MWh 膨胀至 210 MWh，对应 8.4 万美元电费（按 $0.04/kWh 工业电价）。边际收益曲线在采样次数 32 处出现拐点：32 次采样的准确率提升 18.7 个百分点，64 次仅再提升 2.1 个百分点，每百分点边际能耗从 0.52 J 跃升至 2.7 J。Test-Time Compute 不是免费午餐，是功耗的指数税。

二、架构解剖：KV Cache 碎片化与 HBM 容量墙的数学死刑

KV Cache 是推理架构的隐形杀手。以 Llama-3 70B 为例：80 层、64 个 KV 头、head dim 128，FP8 精度下每 token 的 KV 占用为 2×80×64×128×1 Byte = 1.31 MB。128K 上下文单请求即 167.8 MB。单颗 192GB HBM3e 扣除 70GB 权重与 20GB 激活缓冲后剩 102GB 可用，理论并发上限 607 个请求。但 PagedAttention 的块分配（block size 16）在真实负载下产生 23%-31% 的内部碎片，有效并发跌至 418-467。当并发达到 500 时，KV Cache 换出至 NVLink 连接的 peer HBM，900GB/s 双向带宽在 128K 上下文下每换出 1GB 需 1.11 毫秒，而解码步进仅 20.9 微秒——NVLink 瞬间成为 53 倍超载的拥塞节点。

SRAM 方案是纸上谈兵。Groq 式片上 SRAM 每 mm² 在 5nm 节点仅 1.2 MB，230 MB 的 KV Cache 需 192 mm² 纯 SRAM 面积，叠加权重存储后单 die 面积突破 800 mm² 的光罩极限，良率按 Murphy 模型跌至 31%。HBM4 的 2048-bit 接口将带宽推至 8TB/s，但 TSV 穿孔密度受热密度约束：每堆叠层 40W 功耗在 12 层堆叠下形成 480W 热点，结温每升 10°C 漏电增加 1.8 倍，良率在 8-Hi 以上呈指数衰减。容量墙不是工程问题，是热力学与统计良率的联合死刑。

三、硅光互联：0.8pJ/bit 的交叉点与 18 个月交付黑洞

铜缆互联在 224G SerDes 下的能耗为 1.2 pJ/bit，含均衡与时钟恢复。硅光模块当前实测 1.6 pJ/bit（含激光器偏置与调制器驱动），但共封装光学（CPO）将电链路从 30cm 压缩至 2cm，使系统级能耗降至 0.8 pJ/bit。交叉点在 2026 年 Q3：当单机架互联带宽突破 51.2 Tb/s，铜缆功耗达 61.4 kW，硅光方案降至 41 kW，20.4 kW 的差值在 $0.04/kWh 下每年节省 7,150 美元/机架——但 CPO 的激光器寿命（当前 10,000 小时 MTBF）与光纤耦合良率（92%）将交付周期拖入 18 个月。硅光不是选择题，是时间窗口的囚徒。

推演结论：Test-Time Compute 的算力叙事在 32 次采样处遭遇功耗墙，KV Cache 碎片化使 HBM 有效容量缩水 27%，硅光互联的 0.8pJ/bit 优势被 18 个月交付周期对冲。华尔街为“推理红利”支付的溢价，建立在忽略 3.35TB/s 带宽刚性与 480W TSV 热点的账本之上。物理定律不参与叙事，只执行清算。
