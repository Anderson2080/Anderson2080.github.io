一、算力账本：伪命题与物理极限

先清算“Test-Time Compute”的数学基础。假设一个70B参数MoE模型，激活参数28B，在FP8下每Token需执行约5.6×10^10次FLOP。当上下文窗口为100K时，KV Cache占用显存为：2（K和V）×100K×128（头数）×128（维度）×2字节（FP8）=6.55GB。加上权重56GB（28B×2字节），单请求驻留内存62.55GB。HBM3e的8TB/s峰值带宽，扣除TCAM刷新（每2μs一次，占带宽7%）和Bank冲突损耗（实测约23%），有效带宽仅5.6TB/s。单Token生成延迟下限 = 62.55GB / 5.6TB/s = 11.2毫秒。这是纯内存搬运时间，不含任何计算。

现在推演并发场景。一个8卡H100节点，总HBM容量640GB，但NVLink域内聚合带宽仅900GB/s。当512个并发请求同时到达，每请求需搬运62.55GB，总数据量32TB。在理想流水线下，节点需耗时35.6秒完成首Token分发。但NVLink的实际有效吞吐在双向流量下衰减至60%，即540GB/s。排队论M/D/1模型给出平均等待时间 = ρ/(2μ(1-ρ))，其中ρ=32TB/(540GB/s×35.6s)=1.66>1，系统直接过载。结论：任何宣称支持1000并发×100K上下文的推理卡，其架构在物理上不可能实现。

二、架构解剖：为什么现有方案是纸上谈兵

SRAM的物理面积账本：一个7nm工艺的SRAM单元面积0.042μm²，每bit需6个晶体管。要在芯片上集成64MB的片上缓存，需占用268mm²——这已超过H100的Die面积（814mm²）的三分之一。而64MB仅能容纳FP8下的8K上下文KV Cache（8K×128×128×2=268MB，需4倍容量）。因此，任何声称“用SRAM解决内存墙”的方案，其面积成本将导致计算密度下降至不可接受的水平。

硅光互联的能效悖论：在2米距离内，铜缆（如NVLink 4.0）的能效为0.8pJ/bit，而硅光模块需经过电-光-电三次转换，总能耗2.4pJ/bit——是铜缆的3倍。只有当距离超过10米（机柜间互联），硅光才以0.7pJ/bit胜出。但问题在于，当前所有推理集群的瓶颈在机柜内（NVLink域），而非机柜间。用硅光解决机柜内互联，等于用波音747送外卖——成本结构完全错配。

KV Cache碎片化的数学灾难：PagedAttention将显存分为固定大小的Page（如512字节）。当多请求交错执行，Page利用率呈二项分布。实测在混合工作负载下，碎片率（空闲Page占总Page比例）达15%时，有效显存利用率 = 1 - (1-0.15)^(1/PageSize) ≈ 68%。这意味着，标称80GB的H100，实际只能承载54.4GB的KV Cache。以FP8、100K上下文计算，单卡并发上限从理论值（80GB/6.55GB=12）暴跌至8.3。每Token成本因此上升44%。

三、成本清算：每Token的真实物理账单

以8卡H100节点为例，硬件成本（折旧3年）为$250,000/3年/365天/24小时 = $9.5/小时。功耗：8卡×700W + 网络与散热 = 6.8kW，按$0.15/kWh计，$1.02/小时。总运营成本$10.52/小时。在最优工况（无碎片、无拥塞）下，节点每秒可生成Token数 = 5.6TB/s / 62.55GB/Token = 89.5 Token/s。每Token成本 = $10.52 / (89.5×3600) = $0.0000327。但计入15%碎片率（有效吞吐降至76 Token/s）和NVLink拥塞（再降30%至53 Token/s），实际成本 = $10.52 / (53×3600) = $0.0000551/Token。这比训练阶段的每Token成本（约$0.000005）高出一个数量级。

更致命的是扩展性：当集群规模从8卡增至64卡（8节点），NVLink域间通信需通过InfiniBand，其延迟从1.2μs跳升至5μs。在Test-Time Compute的迭代推理场景（每Token需多次前向传播），这一延迟直接叠加至关键路径。以AlphaProof类搜索算法（每Token需32次前向传播）为例，有效吞吐降至53/32 = 1.66 Token/s。每Token成本飙升至$0.00176——这已超过人工标注成本。

四、投资结论：做空“推理革命”，做多“内存堆叠”

数据指向唯一确定性：HBM4的1.2TB/s per stack带宽（相比HBM3e提升50%）和硅通孔（TSV）密度提升，是唯一能缓解内存墙的物理路径。但TSV良率在16层堆叠时降至78%，导致每GB成本上升40%。任何宣称“软件优化解决内存墙”的初创公司，其方案在数学上无法突破带宽物理上限。

对冲策略：做多HBM设备商（TSV刻蚀设备），做空依赖“无限上下文”叙事的软件层公司。Test-Time Compute的泡沫将在2025年Q2财报季破裂——当市场发现每Token成本无法通过规模效应摊薄时，估值将向物理现实回归。
