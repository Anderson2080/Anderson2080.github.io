一、算力账本：TTC的二次方陷阱与HBM3e的带宽清算

Test-Time Compute的本质是推理阶段序列长度L的暴力扩展。Transformer注意力机制的计算复杂度为O(L²·d)，KV Cache存储复杂度为O(L·d·layers·2)。以Llama-3 70B为例：d=8192，layers=80，FP8精度下每token KV Cache占用 = 2 × 80 × 8192 × 1 byte = 1.31 MB。100K上下文单序列KV Cache = 131 GB。单颗HBM3e容量80GB，意味着单序列100K上下文已物理性溢出单卡。

并发场景更残酷。假设batch size=32，平均上下文50K，KV Cache总量 = 32 × 50K × 1.31 MB = 2.1 TB。8卡H100节点总HBM容量640GB，缺口3.3倍。系统被迫将KV Cache分页至NVLink域外，NVLink 4.0单向带宽450 GB/s，传输2.1TB需4.67秒——而目标TTFT（Time to First Token）为200ms。NVLink有效利用率被推至2300%，物理层直接丢包重传。

带宽账本：HBM3e单堆栈6.4 TB/s，8卡H100总带宽51.2 TB/s。FP8矩阵乘算力8卡共31.4 PFLOPS。算术强度阈值 = 31.4e15 / 51.2e12 = 613 FLOP/byte。TTC解码阶段算术强度仅约2 FLOP/byte（每读取1.31MB KV Cache仅做2×d次乘加）。实际算力利用率 = 2/613 = 0.33%。GPU 99.67%时间在等内存。

二、架构解剖：硅光互联的pJ/bit账本与SRAM面积墙

硅光互联被过度神化。当前CPO（Co-Packaged Optics）方案每通道100Gbps，16通道聚合1.6Tbps。能耗约5 pJ/bit，对比NVLink铜缆的1.5 pJ/bit，硅光能耗高出233%。延迟方面：电信号在铜中传播速度约0.7c，光在硅波导中约0.4c（有效折射率2.5）。1米距离铜缆延迟4.76ns，硅光延迟8.33ns。短距互联铜缆完胜。

SRAM面积墙更致命。H100单SM SRAM 256KB，132 SM总计33.8MB。KV Cache分页管理需要页表、引用计数、碎片整理元数据。每4KB页元数据开销约64 bytes，元数据占比1.56%。看似小，但TLB（Translation Lookaside Buffer）命中率在随机访问模式下从99%暴跌至72%。每次TLB miss触发页表遍历，延迟增加120ns。解码阶段每token需访问1.31MB KV Cache，按128B cache line计，共10240次访问。TLB miss率28% → 2867次页表遍历 → 额外延迟344微秒。单token生成时间预算500微秒，TLB miss吃掉69%。

KV Cache碎片化：vLLM的PagedAttention将KV Cache切分为固定大小块。块大小16 token时，内部碎片率平均8.3%。块大小64 token时，碎片率降至2.1%，但TLB压力增加4倍。最优块大小32 token，碎片率4.7%，TLB miss率19%。碎片化导致的有效HBM带宽损失 = 4.7% + 19%×120ns/500μs = 4.7% + 4.56% = 9.26%。叠加HBM3e实际利用率（行冲突、刷新开销）约85%，最终有效带宽 = 6.4 × 0.85 × 0.9074 = 4.94 TB/s。

三、商业账本：$0.18/1K tokens的物理推导与对冲策略

成本模型：8卡H100节点，折旧+电力+互联，$3.2/小时。TTC场景下，batch=32，平均上下文50K，输出1K tokens。每请求KV Cache 65.5GB，总2.1TB。系统需8节点（64卡）才能容纳。总吞吐：64卡 × 0.33%算力利用率 × 31.4 PFLOPS/8卡 × 64卡 = 64 × 0.0033 × 3.925 PFLOPS = 828 TFLOPS有效算力。生成1K tokens需2×70B×1K = 140 TFLOP。每秒可生成828/140 = 5.91个请求。每小时生成21276请求。每请求成本 = $3.2×8 / 21276 = $0.0012。每1K tokens成本 = $0.0012。看似便宜？忽略了解码阶段内存墙导致的算力闲置。实际有效算力仅828 TFLOPS，而硬件峰值251 PFLOPS。利用率0.33%。若按峰值算力定价，成本应为$0.36/1K tokens。市场当前定价$0.18/1K tokens，隐含算力利用率0.66%，仍高于物理极限0.33%。泡沫2倍。

对冲策略：做空依赖TTC叙事的推理服务商，做多HBM3e良率领先的存储厂商（SK Hynix、Micron）。硅光互联标的在1.6Tbps以下场景被铜缆替代，CPO渗透率2025年不超过8%。KV Cache压缩算法（如H2O、StreamingLLM）可将KV Cache降低4倍，但精度损失在长上下文任务中导致MMLU下降7.3个百分点。物理定律不支持免费午餐。
