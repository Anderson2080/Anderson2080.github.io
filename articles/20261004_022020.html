算力绞肉机：当FP8精度撞上100K上下文，80GB HBM3e的物理葬礼与硅光互联的虚假黎明

一、算力账本：伪命题与物理极限

拆解Llama-3-70B在FP8精度下的单请求KV Cache占用。模型维度d_model=8192，层数L=80，KV头数n_kv=8，头维度d_head=128。单Token的KV Cache字节数 = 2 * L * n_kv * d_head * 1 Byte = 2 * 80 * 8 * 128 = 163,840 Bytes ≈ 160 KB。100K上下文长度下，单请求KV Cache = 160 KB * 100,000 = 16 GB。若采用GQA分组查询，n_kv=8已是最优压缩，无法进一步降低。

80GB HBM3e扣除模型权重（70B * 1 Byte = 70GB）后，仅剩10GB可用显存。这意味着FP8精度下，单卡连一个100K上下文的请求都无法完整驻留。若强行并发，KV Cache必须分页卸载至NVLink或PCIe。NVLink 4.0单向带宽450 GB/s，双向900 GB/s。当并发请求数N=4时，每Token生成需同步的KV Cache数据量为4 * 160 KB = 640 KB。以20 Token/s的生成速度计算，NVLink需承载的持续带宽 = 640 KB * 20 = 12.8 MB/s。看似不高，但这是延迟敏感型同步流量。NVLink的微秒级延迟（~1μs）在N=8时，因All-to-All通信模式，有效带宽利用率降至37%，拥塞延迟飙升至15μs以上，直接导致Token生成间隔抖动超过200%。

功耗账本：HBM3e每GB/s带宽功耗约3.5 pJ/bit。8TB/s总带宽下，仅HBM物理层功耗即达 8e12 * 3.5e-12 = 28W。若KV Cache频繁换入换出，HBM的激活-预充电周期功耗增加40%，单卡HBM子系统功耗突破40W。在风冷散热极限下，机架功率密度超过50kW，PUE必须压至1.05以下，否则电费将吞噬推理毛利。

二、架构解剖：为什么现有方案是纸上谈兵

硅光互联的能耗目标<10 pJ/bit是实验室数据。商用微环谐振器（MRR）的热光系数为0.1 nm/K，在300mm晶圆上，工艺温度波动±0.5K导致谐振波长漂移±0.05nm。为锁定波长，需集成微加热器，单个MRR的静态功耗为2-5 mW。一个64通道的WDM链路，仅热调谐功耗即达128-320 mW。折算至每bit能耗，在50 Gbps速率下，热调谐功耗占比超过60%，总能耗突破15 pJ/bit。铜互连在<1m距离内，通过PAM4和重定时器，能耗可压至5 pJ/bit。硅光在2026年前无成本优势。

SRAM面积局限：当前H100的L2 Cache为50MB，采用台积电4N工艺，SRAM bitcell面积约0.021 μm²。若将KV Cache全部驻留SRAM，100K上下文需16GB，即 16e9 * 8 bit = 128e9 bit。所需面积 = 128e9 * 0.021e-12 m² = 2.688e-3 m² = 2688 mm²。单张光罩极限面积858 mm²，需3.13张光罩拼接。Chiplet方案下，跨die互联延迟>10ns，带宽密度受限于 microbump 间距（55μm），每mm边缘仅能提供~18 GB/s。KV Cache碎片化导致SRAM利用率低于40%，实际需6-8张光罩面积，成本呈指数上升。

KV Cache碎片化：PagedAttention将KV Cache切分为16 Token的Block，每个Block 2.5KB。100K上下文需6250个Block。GPU显存分配器在并发请求下，外部碎片率高达35%。为维持吞吐，需预留20%显存作为缓冲，进一步压缩可用容量。在N=8并发时，有效显存利用率降至 10GB * (1-0.35-0.2) = 4.5GB，仅能支撑2.8个100K请求。NVLink成为唯一的数据交换通道，但其协议栈在All-to-All模式下，因信用（Credit）流控机制，有效带宽降至 900 * 0.37 = 333 GB/s。每Token同步延迟 = 640KB / 333GB/s = 1.92μs，叠加协议栈开销，实际>5μs。生成速度被硬性限制在 1/5μs = 200K Token/s的理论上限，但受限于HBM延迟，实际<50 Token/s。

三、Test-Time Compute的数学死刑与商业账本

Test-Time Compute的Scaling Law假设：推理算力随思考时间线性增长，准确率随之提升。但物理约束是：每增加1秒思考时间，需额外生成T个Token，KV Cache线性增长 T * 160 KB。在FP8下，HBM3e的8TB/s带宽被KV Cache读写占用。以T=1000 Token/s的思考速度，KV Cache读写带宽 = 1000 * 160KB = 160 GB/s。看似仅占2%，但这是随机访问模式，HBM的行激活命中率低于60%，有效带宽降至 8 * 0.6 = 4.8 TB/s。KV Cache占用3.3%。

当并发请求N=16时，KV Cache读写带宽 = 16 * 160 GB/s = 2.56 TB/s，占有效带宽的53%。HBM进入拥塞状态，延迟从~100ns飙升至>500ns。Token生成速度下降60%。商业账本：单卡推理吞吐从 20 Token/s 降至 8 Token/s。以每Token 0.002美元计价，单卡日收入从 3456美元 降至 1382美元。而HBM3e的折旧成本为 3000美元/年，即 8.2美元/天。电费按 700W TDP，0.1美元/kWh，日耗电 16.8 kWh，成本 1.68美元。毛利从 3456 - 8.2 - 1.68 = 3446美元 降至 1382 - 8.2 - 1.68 = 1372美元。降幅60.2%。

若采用HBM4，带宽翻倍至16TB/s，但TSV热密度从 0.5 W/mm² 升至 1.2 W/mm²。结温从85°C升至105°C，漏电流增加3倍。HBM4的每GB/s功耗升至5 pJ/bit，总功耗 16e12 * 5e-12 = 80W。散热方案需从风冷切换至液冷，单机架CAPEX增加40%。物理定律不接受线性外推。任何基于Test-Time Compute的估值模型，必须扣除KV Cache碎片化导致的35%显存税，以及NVLink拥塞导致的60%吞吐衰减。当前市场对推理算力的定价，隐含了零摩擦的显存访问和无限带宽的互联，这是热力学第二定律不允许的永动机。
