一、算力账本：伪命题与物理极限

Test-Time Compute 的叙事是“用更多推理换取更高智能”，但账本上写的是：每次额外推理 token 需要 2×N×L 次 FLOPs（N=模型维度，L=层数），而 HBM3e 的带宽上限是 5.6TB/s。以 70B 参数模型、FP8 精度为例，单 token 生成需读取 70GB 权重，理论最小延迟为 70GB / 5.6TB/s = 12.5ms。若并发 100 个请求，每个请求上下文 100K tokens，KV Cache 占用 2×100K×80×2bytes = 32GB，直接挤爆 80GB HBM3e 的 40% 容量，剩余带宽仅 3.36TB/s，单 token 延迟飙至 20.8ms——这是纯物理延迟，与算力无关。

更残酷的是功耗账本：HBM3e 的每 bit 读写功耗为 4pJ，5.6TB/s 带宽意味着 22.4W 的固定功耗，而 GPU 核心在 FP8 下的峰值能效为 0.5pJ/FLOP，70B 模型单 token 推理需 2×70×80×2 = 22.4 TFLOPs，功耗 11.2W。总功耗 33.6W 中，内存占 67%——这不是“算力瓶颈”，是“存储功耗瓶颈”。市场鼓吹的“推理成本下降”在物理账本上不成立：HBM 堆叠层数每增加 4 层，TSV 穿孔热密度上升 18%，良率下降 12%（Exhibit 1 数据），这意味着 2025 年 HBM4 的 16 层堆叠良率将跌破 60%，单位成本飙升 1.7 倍。

二、架构解剖：为什么现有方案是纸上谈兵

NVLink 的 900GB/s 双向带宽在纸面上是救世主，但物理拓扑暴露了真相：8 卡 GPU 的全互联需要 28 条链路，每条链路 100GB/s，而 PCB 走线损耗在 56Gbps 速率下达到 3dB/inch，迫使信号功率从 1.2V 升至 1.8V，功耗翻倍。更致命的是延迟：NVLink 的 1.3μs 端到端延迟在 KV Cache 命中率低于 90% 时，每轮推理需 3 次跨卡访问，累计 3.9μs——这比 HBM 的 400ns 延迟高出 10 倍，直接成为系统瓶颈。

硅光互联的 pJ/bit 优势（0.5pJ/bit vs 铜线的 12pJ/bit）在 2m 封装内被 SerDes 的 12pJ/bit 功耗打回原形：光模块的 EML 激光器需 20mA 驱动电流，8 通道即 160mA，功耗 0.8W，加上 TIA 的 0.4W，总功耗 1.2W，而铜线方案仅需 0.6W。硅光的真正价值在 100m 以上跨机柜互联，但那是数据中心级，不是芯片级——市场混淆了这两个尺度，导致“硅光替代铜线”的叙事在封装内是伪命题。SRAM 面积局限更直接：一个 80MB 的 SRAM 缓存（用于 KV Cache）在 5nm 工艺下占用 12mm²，占芯片总面积的 15%，而 100K 上下文的 KV Cache 需 32GB，即使压缩 4 倍（INT8 量化），仍需 8GB——这需要 1000 个 8MB SRAM 块，面积 1200mm²，是单芯片面积的 3 倍。结论：KV Cache 必须外置，但外置意味着带宽和延迟的指数级恶化。

三、KV Cache 碎片化：被忽视的 60% 算力折扣

KV Cache 的碎片化不是软件问题，是内存分配器的物理诅咒。当 100 个并发请求各自持有 32GB 的 KV Cache，且每个请求的 token 长度动态变化（从 1K 到 100K），内存分配器在 80GB HBM 中产生 40% 的碎片率——这意味着有效带宽从 5.6TB/s 降至 3.36TB/s，算力利用率从 95% 降至 57%。更糟的是，碎片化导致的内存迁移（memcpy）在 HBM 上以 200GB/s 的速度运行，每次迁移 1GB 数据需 5ms，而推理延迟预算仅 20ms——25% 的时间浪费在内存整理上。

推演极端场景：一个 100K 上下文的请求，KV Cache 占用 32GB，若碎片化导致 10% 的 cache 行需要迁移，即 3.2GB 数据，迁移时间 16ms，加上计算延迟 20.8ms，总延迟 36.8ms——超出实时推理阈值（30ms）22%。市场宣称的“长上下文推理”在物理上不可行，除非放弃碎片整理，但那意味着 40% 的 HBM 容量被浪费，等效于每 GB 成本增加 67%。

四、商业账本：谁在裸泳，谁在造桥

基于以上物理参数，2025 年 100K 上下文推理的单 token 成本为：HBM 功耗 22.4W × 0.1 美元/kWh × 20.8ms = 0.013 美分，加上 GPU 核心 11.2W × 0.1 × 20.8ms = 0.006 美分，总成本 0.019 美分/token。若并发 1000 请求，HBM 带宽饱和，成本线性上升至 0.19 美分/token——这是当前 API 定价（0.03 美分/token）的 6.3 倍。市场定价与物理成本脱节，意味着所有依赖长上下文推理的商业模式都在补贴用户。

硅光互联的救赎在于 100m 以上跨机柜：800G 光模块的 pJ/bit 为 2pJ，而铜线在 100m 时需中继器，总功耗 15pJ/bit，硅光节省 87% 功耗。但 2025 年 800G 光模块成本 1200 美元，而铜线仅 300 美元，回本周期需 3 年——只有超大规模数据中心（>10 万 GPU）才能摊薄。结论：硅光不是芯片级方案，是数据中心级方案，市场叙事错位。
