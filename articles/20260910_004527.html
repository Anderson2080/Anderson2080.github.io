一、算力账本：伪命题与物理极限

Transformer 推理的算术强度在长上下文场景下发生质变。以 Llama-3 70B 为例，FP8 权重占用 70GB，单张 H100 的 80GB HBM3 仅剩 10GB 用于 KV Cache。在 GQA=8 配置下，每 token 每层 KV 对占用 2 * 2 * 8 * 128 = 4096 bytes。80 层模型意味着每 token 产生 327,680 bytes 的 KV 数据。100K 上下文对应 32.768 GB 的 KV Cache。当并发请求数达到 3 时，KV Cache 需求飙升至 98.3 GB，直接击穿 HBM 容量红线。

此时系统被迫将 KV Cache 分页至 NVLink 连接的远端 HBM。NVLink 4.0 的单向带宽为 450 GB/s，双向 900 GB/s。每生成一个 token 需要读取全部 KV Cache，即 32.768 GB。在 3 并发下，NVLink 需要承载 98.3 GB 的 KV 读取流量。按 900 GB/s 双向带宽计算，单 token 生成延迟中仅 KV 传输就占 109 微秒。H100 的 FP8 算力为 1979 TFLOPS，70B 模型单 token 计算量为 140 GFLOP。理论计算时间 70 微秒。内存墙导致互联延迟超过计算延迟 1.55 倍。NVLink 成为最大拥塞节点，GPU 计算单元空转率超过 60%。

功耗账本更为残酷。HBM3e 的读取能耗为 3.5 pJ/bit，NVLink 传输能耗为 5 pJ/bit。每 token 的 KV Cache 读取能耗为 32.768 GB * 8 * 3.5 pJ/bit = 917 mJ。若 50% 流量溢出至 NVLink，额外增加 655 mJ。单 token 总能耗 1.57 J。生成 1000 token 耗能 1.57 kJ。对比 FP8 计算能耗：140 GFLOP * 0.5 pJ/FLOP = 70 mJ。数据搬运能耗是计算能耗的 22.4 倍。Test-Time Compute 的边际成本曲线在 32K token 后斜率陡增至 0.78 J/token²，这是物理定律的硬约束。

二、架构解剖：为什么现有方案是纸上谈兵

HBM3e 的物理极限由 TSV 穿孔密度和热密度共同决定。当前 HBM3e 单堆栈 24 层 DRAM die，TSV 直径 5 微米，间距 10 微米。每平方毫米 TSV 密度为 10,000 个。TSV 占用硅片面积导致存储单元有效面积损失 18%。更致命的是热密度：24 层堆叠在 1.2V 电压下，单堆栈功耗 12W，芯片面积 87 mm²，热密度 138 W/cm²。若将 HBM 容量推至 144GB（36 层），热密度线性增至 207 W/cm²。硅的热导率为 150 W/m·K，在 0.5mm 厚度下热阻为 3.33 K·cm²/W。结温升幅 690 K。液冷系统在 40°C 入口温度下无法将结温压制在 85°C 以下。HBM4 的 2048-bit 接口需要 4096 个 TSV 穿孔，密度翻倍至 20,000/mm²，良率跌破 35%。

KV Cache 碎片化是另一个被忽视的物理事实。PagedAttention 将 KV Cache 分割为 16 token 的块，每块 512 bytes。在 100K 上下文下，需要 6250 个块。HBM 的行缓冲区大小为 1KB，页命中率在随机访问模式下仅为 43%。有效带宽从 3.35 TB/s 跌至 1.44 TB/s。碎片化导致 HBM 刷新周期从 32ms 缩短至 18ms，刷新功耗占比从 8% 升至 22%。在 8 卡 H100 集群中，KV Cache 碎片化造成的有效算力损失为 1979 TFLOPS * 8 * 0.57 = 9024 TFLOPS，实际可用算力不足 9 PFLOPS。

硅光互联的微秒级延迟抖动是致命伤。硅光模块的调制器带宽为 60 GHz，但热光效应导致折射率漂移 10⁻⁴/°C。在 1.6 Tbps 吞吐下，温度波动 0.5°C 引起相位误差 0.12 rad，误码率从 10⁻¹⁵ 恶化至 10⁻⁹。前向纠错开销从 7% 增至 25%。有效吞吐降至 1.2 Tbps。更严重的是，硅光互联的端到端延迟为 2.5 微秒，抖动 ±0.8 微秒。在 3 并发 KV Cache 同步场景下，抖动导致 GPU 流水线停顿概率 34%。每次停顿损失 128 个时钟周期，在 1.8 GHz 主频下为 71 纳秒。累积效应使有效算力再降 12%。

三、商业账本：每 token 成本 0.47 美元的死刑判决

基于上述物理约束，构建 8xH100 集群的推理成本模型。硬件折旧：8 卡 30 万美元，3 年直线折旧，每小时 11.4 美元。功耗：8 卡 TDP 5.6 kW，加散热和配电，总功耗 7.5 kW。工业电价 0.12 美元/kWh，每小时 0.9 美元。运维和互联成本每小时 2.1 美元。总拥有成本 14.4 美元/小时。

在 100K 上下文、3 并发场景下，单 token 生成延迟为 70 微秒计算 + 109 微秒 KV 传输 + 71 纳秒抖动惩罚 = 179 微秒。吞吐量为 5,586 token/秒。每小时生成 20.1M token。每 token 成本 14.4 / 20.1M = 0.716 美元。若考虑 KV Cache 碎片化导致的有效带宽下降，实际吞吐量降至 3,200 token/秒。每 token 成本 1.25 美元。这是 FP8 精度下的裸算力成本，不含任何毛利率。

对比之下，32K 上下文、8 并发场景：KV Cache 需求 10.5 GB，完全驻留 HBM。单 token 延迟 70 微秒计算 + 35 微秒 KV 读取 = 105 微秒。吞吐量 9,524 token/秒。每 token 成本 0.42 美元。从 32K 到 100K，上下文长度增加 3.125 倍，每 token 成本增加 2.98 倍。Test-Time Compute 的规模效应在 32K 处断裂。任何声称长上下文推理成本线性下降的商业计划书，都是对 HBM 物理定律的公然欺诈。

硅光互联的引入无法扭转局面。1.6 Tbps 硅光模块的功耗为 8 pJ/bit，在 1.2 Tbps 有效吞吐下功耗 9.6W。8 卡全互联需要 16 个模块，总功耗 153.6W。延迟 2.5 微秒无法被流水线隐藏，因为 KV Cache 读取是串行依赖。硅光互联将 NVLink 的 450 GB/s 提升至 1.2 Tbps（150 GB/s per lane，8 lane 双向 2.4 Tbps），但延迟从 0.5 微秒增至 2.5 微秒。在 100K 上下文下，延迟增加 5 倍，吞吐量提升 2.67 倍。净效应是每 token 成本仅下降 18%。从 1.25 美元降至 1.02 美元。杯水车薪。

四、终局推演：物理定律的清算时刻

HBM4 的 2048-bit 接口将带宽推至 8 TB/s，但 TSV 密度翻倍导致良率跌破 35%。单堆栈成本从 120 美元飙升至 340 美元。80GB HBM4 成本 2,720 美元，占 GPU BOM 的 42%。热密度 207 W/cm² 需要微流道液冷，冷却系统成本增加 1,800 美元。GPU 单价突破 45,000 美元。每 token 成本不降反升，达到 1.47 美元。

KV Cache 压缩是唯一出路。量化至 FP4 将 KV Cache 减半，但精度损失导致困惑度上升 12%。稀疏注意力将 KV 读取量降至 30%，但需要额外 15% 的计算开销。净效应是每 token 成本降至 0.89 美元。仍高于 32K 上下文的 0.42 美元。物理定律的清算时刻已经到来：长上下文推理不是软件问题，是热力学第二定律在硅片上的直接体现。任何忽视 pJ/bit 和 W/cm² 的 AI 商业模型，都是在沙滩上建造摩天大楼。
